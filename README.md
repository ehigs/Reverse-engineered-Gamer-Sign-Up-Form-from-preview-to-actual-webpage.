# Reverse-engineered-Gamer-Sign-Up-Form-from-preview-to-actual-webpage.
This repository contains a fully responsive, web page reverse engineered from a  design mockup into a functional, single-page signup flow. Built with a dark cyber-arcade visual theme, complete with real-time field validation, dynamic side-panel HUD diagnostics and automated state management.
My frontend mentor challenge was to build a sign-up form for NEONCORE, a competitive-gaming network and get it looking as close to the design as possible.
I applied google gemini, Tailwind CSS, HTML5 and Vanilla Javascript.
open the project files locally, and run the app in a web browser.
